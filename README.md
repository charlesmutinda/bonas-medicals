# Bonas Medicals - Orthopedic Hospital Website Template (PHP)

Bonas Medicals is a modern, responsive PHP website template designed for an Orthopedic & Spine Surgery hospital, inspired by premier healthcare platforms such as *The Nairobi Hospital*.

## Features
- **Top Utility & Emergency Bar**: 24/7 Trauma line, OPD hours, and Patient Portal links.
- **Hero Banner & Floating Quick Action Strip**: Instant access to *Find a Specialist*, *Book Visit Online*, *24/7 Fracture Emergency*, and *Physical Therapy*.
- **Specialty Clinical Pages**: Total Joint Replacement, Spine & Scoliosis Surgery, Sports Medicine Arthroscopy.
- **Interactive Doctor Directory**: Filterable by orthopedic sub-specialty.
- **Online Booking System**: Modal pop-up & full registration form with date/time slot picker and PHP validation.

## Local Setup
1. Clone or copy this repository into your local web server root folder (e.g. `htdocs/projects/bonas-medicals` for XAMPP).
2. Open your web browser and navigate to `http://localhost/projects/bonas-medicals/index.php`.
